# 打字机效果 + 性能监控

纯前端单页应用，无构建依赖。直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 功能

- 输入文本，以打字机效果逐字显示（单文本节点增量 `appendData`，10 万字不卡）
- 速度调节（1–2000 字/秒，高速时每帧多字）、暂停 / 继续 / 重置
- 实时指标：FPS、帧耗时、已显示字符数、剩余时间估算、长任务数、降级状态
- Canvas 绘制 FPS 历史曲线（含 60 FPS 参考线）

## 技术要点

- **DOM + requestAnimationFrame**：按 dt 累积小数进位推进字符，速度平滑
- **后台恢复不跳字**：单帧 dt 夹紧到 100ms，`visibilitychange` 时重置计时基准
- **暂停/继续位置精确**：暂停时把未写入 DOM 的字符一次性补齐，恢复时从原位置继续
- **低端设备自动降级**：FPS 持续低于 45 超过 1.5s 自动降低 DOM 写入频率
  （每帧 → 每 2/4/8 帧），恢复到 55 FPS 以上 5s 后逐级回升
- **PerformanceObserver**：监听 `longtask` 统计长任务（不支持的浏览器显示"不支持"）
